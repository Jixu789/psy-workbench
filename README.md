# 心理老师工作台

给中学心理老师用的单文件网页工作台：日常待办、个案台账（仅代号）、课程排期、自我关照、活动筹备、学期目标、素材灵感。

## 在线使用

- 入口：https://jixu789.github.io/psy-workbench/
- 手机版：https://jixu789.github.io/psy-workbench/mobile.html
- 电脑版：https://jixu789.github.io/psy-workbench/desktop.html

手机上打开后点浏览器菜单「添加到主屏幕」，即可像 App 一样使用。

## 说明

- 页面为单文件 HTML，图片已内嵌，不依赖外部资源。
- 数据只保存在本机浏览器的 localStorage，不上传、不联网、不跨设备同步。
- 个案栏只写「学生A / 学生B」这类代号，不要写真实姓名、班级、联系方式。
