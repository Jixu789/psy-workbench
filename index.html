心理老师工作台

PSY · TEACHER WORKBENCH

日常待办、个案台账、课程排期、自我关照，都在一个页面里。数据默认只存在你自己的浏览器，不上传、不联网；想让手机和电脑共用同一份数据，可在两端各填一次令牌开启同步（可选，随时可关）。

手机用

手机版

竖向布局，单手可操作。打开后点浏览器菜单「添加到主屏幕」，就是一个 App 图标。

进入手机版 →
 电脑用

电脑版

三栏布局，待办、课程、个案台账同屏。建议加到浏览器书签栏。

进入电脑版 →
关于数据：默认只保存在「当前这台设备、这个浏览器」里，清理浏览器缓存会丢失。
关于同步（可选）：在电脑版左下角、手机版抽屉最下面各点一次「同步设置」，填入同一个 GitHub 令牌即可。之后任一端改动约 15 秒内另一端自动更新，数据放在你自己账号下的私有仓库里，不经过第三方服务器。
同步范围：待办、自我关照、课程排期、活动筹备、学期目标、素材灵感；个案台账不同步，只留在本机。
个案栏只写「学生A / 学生B」这类代号，不要写真实姓名、班级、联系方式。
