心理老师工作台 · 使用说明
====================================

最省事的方式：直接打开网址
------------------------------------
https://jixu789.github.io/psy-workbench/

手机浏览器打开上面这个地址（建议用 Safari / Chrome / 微信内置浏览器），
点菜单「添加到主屏幕」，桌面上就多一个「心」图标，以后一点就开。
电脑浏览器打开同一个地址即可，建议加到书签栏。

· 手机版直达： https://jixu789.github.io/psy-workbench/mobile.html
· 电脑版直达： https://jixu789.github.io/psy-workbench/desktop.html
· 上面三条都不需要联网下载任何东西，打开即用（页面本身是单文件）。


这个压缩包里有什么（离线备用）
------------------------------------
1. 工作台-手机版.html    ← 手机上用（单文件，图片已内嵌）
2. 工作台-电脑版.html    ← 电脑上用（单文件，图片已内嵌）
3. 模板库\               ← 11 套 wps 原版模板（.pptx 原件，模板卡里可一键打开）
4. 情绪管理_初中_暖阳手账.pptx  ← 示范课件（15 页，含讲师备注）
5. 情绪管理_初中_薄荷成长.pptx  ← 同一个课件，薄荷绿配色
6. 情绪管理_初中_星空夜话.pptx  ← 同一个课件，深蓝配色
7. 使用说明.txt          ← 就是这份文件

网络不方便时用压缩包里的 html，效果和网址打开完全一样。
「模板库」文件夹要和两个 html 放在同一层，模板卡里的「打开原版 PPT」才打得开。
手机和电脑想共用一个数据？见第四节「手机和电脑怎么实时同步」。


一、电脑上怎么打开
------------------------------------
1. 把压缩包解压（右键 → 解压到当前文件夹）。
2. 双击「工作台-电脑版.html」，会用浏览器打开。
   · 推荐 Edge 或 Chrome。
   · 建议把它拖到浏览器书签栏，下次一点就开。
3. 课件直接双击 .pptx，用 PowerPoint / WPS 打开。
   放映时用「演示者视图」，能看到每页下方的讲师备注。


二、手机上怎么打开（重点）
------------------------------------
手机浏览器不允许直接双击文件，需要按下面任一种方式：

【方式 A · 最简单，安卓手机】
1. 微信里把「工作台-手机版.html」发给自己（文件传输助手）。
2. 在微信里点开这个文件 → 右上角「…」→「用其他应用打开」→ 选「浏览器」。
3. 打开后点浏览器菜单「添加到主屏幕」，以后像 App 一样点开。

【方式 B · 苹果手机 / 想更稳定】
1. 微信里点开 html → 右上角「…」→「用其他应用打开」→「存储到"文件"」。
2. 打开「文件」App，找到它，长按 →「共享」→「在 Safari 中打开」。
   （iOS 对本地网页限制较多，如果打不开，用方式 C。）

【方式 C · 最稳，两边都能用】
把「工作台-手机版.html」上传到任意网盘并生成分享链接，
手机浏览器打开该链接即可；电脑也能用同一个链接。
需要长期用、还想换手机也不丢数据，建议放静态托管（如 GitHub Pages、
Gitee Pages、Vercel），得到一个固定网址，手机加到主屏幕就行。


三、数据存在哪里（务必知道）
------------------------------------
· 默认情况下，所有记录只存在「当前这台设备的这个浏览器」里，不上云。
· 不开启同步时，电脑版和手机版是两份独立数据，各记各的。
· 清理浏览器数据 / 换浏览器 / 换手机，之前的记录会消失。
· 想留底：重要内容定期复制到微信收藏或文档里。
· 个案台账只写「学生A / 学生B」这类代号，不要写真实姓名、班级、
  联系方式——这不是学校正式档案，正式档案请走学校规定的加密存档。
· 关于同步的隐私边界，见下一节。


四、手机和电脑怎么实时同步
------------------------------------
默认是关闭的，需要自己开一次，之后永久有效（换设备要重新配一次）。

【准备一个 GitHub 令牌（只需做一次，约 2 分钟）】
1. 浏览器打开 https://github.com/settings/tokens/new?scopes=gist
   （没有 GitHub 账号先注册一个，免费，可以只用小号）
2. 「Note」随便写，比如 psy-workbench-sync；
   「Expiration」建议选 90 days 或 No expiration；
   下面的权限只勾选「gist」这一项，其它一律不要勾。
3. 拉到页面最底部点「Generate token」，复制生成的那串字符
   （形如 ghp_xxxxxxxx，只显示这一次，先粘到备忘录里存好）。

【在两端各填一次】
4. 电脑版：左下角「已同步 / 未开启同步」那一行 → 点「同步设置」→
   粘贴令牌 → 点「连接并同步」。
5. 手机版：打开抽屉菜单，最下面一行「同步设置」→ 粘贴同一个令牌 →
   点「连接并同步」。
   · 第一台连上时会自动新建一份「私有 gist」当云端仓库；
     第二台连上时会自动找到这份仓库并合并数据，不用手动配对。

【之后怎么工作】
6. 任何一端改动后约 1~2 秒自动上传；另一端每 15 秒自动拉取一次，
   切回页面时也会立刻拉取。也就是说：手机改完，电脑十几秒内就能看到；
   电脑改完，手机同样。不需要点任何按钮。
7. 同步范围：待办、自我关照、课程排期、活动筹备、学期目标、素材灵感。
   ⚠ 「个案台账」不参与同步，只留在本机 —— 学生信息不出设备。
8. 云端数据放在你自己账号下的私有 gist 里（不公开、不能被搜索到），
   用你的令牌才能读写。工作台本身不经过任何第三方服务器。
9. 底部状态条显示「已同步 · 03:56」表示最近一次成功；
   显示「同步失败」时点「同步设置」看提示（多半是令牌过期或断网）。
10. 想停用：点「断开同步」，本机数据保留，只是不再上传下载。
    想彻底删除云端副本：到 GitHub → 你的 Gists 里删掉那份私有 gist。

· 提示：令牌相当于密码，别发给别人、别写进群里。
  万一泄露，到 GitHub 的 Settings → Developer settings → Tokens 里删掉即可。


五、自己一键生成课件（手机 / 电脑都可以）
------------------------------------
【电脑版】左侧「课程排期」下面有一个「一键出课件」，点进去。
【手机版】点左上角菜单 → 抽屉里「课程排期」下面的「一键出课件」。
两边界面不同，步骤一样：

1. 选主题（情绪管理 / 考试焦虑 / 人际交往 / 青春期 / 新生适应 / 生涯规划），
   也可以自己输入主题，套通用结构。
2. 选学段、时长（20 / 40 / 45 分钟）、版式、视觉模板
   （默认「自动匹配」；点「模板库 · 11 套」按钮可从 11 套原版模板里任选，见下）。
   配色、字体、版式几何都由所选模板接管，页面上不再单独调色。
   · 版式有两种：
     「智能版式」（默认）——先定结构再上色：按内容自动选版式（封面 / 目标 / 提问 /
       观点 / 三栏 / 流程 / 时间线 / 案例 / 清单 / 呼吸练习 / 数字小结 / 卡片 /
       求助页 / 讲师页 / 结束页），共 15 页 13 种版式；装饰母题（圆角色块 / 波浪 /
       网格 / 圆点 / 纸胶带 / 叶形 / 画框）跟着所选模板走，导出的是可编辑的原生形状。
     「海报卡片」——上一版的高饱和色块风格，喜欢更「燃」的课堂气氛可以用它；
       它只吃配色、不套模板的版式几何，所以选了模板建议留在「智能版式」。
   · 视觉模板（11 套，来自真实 wps 模板库）：
     这 11 套不是「仿」出来的配色，而是直接把 11 份原版 .pptx 存进了压缩包的
     「模板库」文件夹；网页里内置了每份的第一页作为封面，版式、字体、装饰母题
     都按原文件实测抽取。
     「自动匹配」（默认）——按主题词、学段、版式自动挑一套最贴的，
       例如「小学一年级 · 友谊」→ 可爱兔子，「危机干预 / 欺凌」→ 小清新动物教学，
       「时间管理 / 复习方法」→ 可爱小怪兽；选中后下面一行会写明
       「自动匹配 → 可爱小怪兽（来源 4.pptx · 字体 幼圆 / 微软雅黑）」。
     「模板库」按钮——就在「自动匹配」下面，按钮上直接写着当前用的是哪套：
       左边一块渐变（这套模板的主色），中间两行字
       「已选 · 可爱小怪兽」/「图像分栏 + 阶梯编号 + 编号徽章 + 三栏卡片 · 点此更换」，
       右边写「模板库 · 11 套」。点开是一张 13 卡的弹层：
       AI 自动匹配（横跨整行的推荐大卡）、基础配色、加 11 套模板。
       · 11 张模板卡的封面就是那份 .pptx 的第一页（720×405 真实截图），
         看到的是原件长什么样，不是换色示意图；
       · 每张卡下方还有一个「↓ 打开原版 PPT」，点它直接打开 / 下载那份原件，
         想照着原模板改、或拿去做别的课件都可以；
       · 卡上两行说明：这套的版式几何，以及为什么推荐它
         （如「主题含「焦虑」 · 初中适配」）；
       · 当前生效的那张卡有强调色描边；点任意一张立即套用并关掉弹层，
         视觉预览、模板说明、导出的 pptx 一起变；
       · 点第一张「AI 自动匹配」就回到「让系统按主题挑」；
         点「基础配色」则不套模板，只回到内置默认配色（暖阳手账）。
       · 11 套模板一览（名字 · 原文件 · 版式几何 · 适合的课）：
       ① 可爱兔子        01_可爱兔子.pptx        居中堆叠 + 四象限 + 双栏卡片 · 小学低段可爱插画
       ② 可爱小怪兽      02_可爱小怪兽.pptx      图像分栏 + 阶梯编号 + 三栏卡片 · 规则 / 方法 / 时间管理
       ③ 卡通油画质感    03_卡通油画质感.pptx    居中堆叠 + 双栏大号 + 三栏卡片 · 中学稳重学术
       ④ 卡通教学通用    04_卡通教学通用模板.pptx 右对齐大字 + 侧栏大字 + 四宫格图标 · 同伴交往
       ⑤ 卡通手绘说课    05_卡通手绘说课.pptx    手账信纸 + 手写清单 + 手写标注 · 日记 / 反思
       ⑥ 卡通风教学通用  06_卡通风教学通用.pptx  左文右图 + 通栏条目 + 大号序号 · 激励 / 行动清单
       ⑦ 小清新动物教学  07_小清新动物教学.pptx  上图下文 + 右侧条目 + 杂志细线 · 危机干预 / 欺凌
       ⑧ 卡通手绘课件    08_卡通手绘课件.pptx    居中堆叠 + 居中条目 + 图文叙事 · 家庭 / 亲子
       ⑨ 快乐的恐龙      09_快乐的恐龙.pptx      右对齐大字 + 右侧条目 + 左图右文 · 正念放松
       ⑩ 食品安全主题班会 10_食品安全主题班会.pptx 插画框景 + 四象限 + 图文叙事 · 小学绘本故事
       ⑪ 可爱泡泡        11_可爱泡泡.pptx        奶油色块 + 圆标编号 + 圆点三栏 · 自我认识 / 青春期
     · 选模板换的不是颜色，是一整套设计 DNA：
       ① 配色——每套 9 个色值（底色 / 深底 / 卡片 / 主文 / 次文 / 主色 / 辅色 /
          柔和色 / 描边）；
       ② 字体——标题字体 + 正文字体，各带缺字回退；
       ③ 装饰母题——圆角色块 / 波浪 / 竖网格 / 圆点 / 圆点阵 / 极简细线 /
          纸胶带 / 叶形 / 画框；
       ④ 版式几何——封面构图（居中堆叠 / 图像分栏 / 右对齐大字 / 左文右图 /
          上图下文 / 手账信纸 / 插画框景 / 奶油色块）、目录排法（四象限 /
          阶梯编号 / 双栏大号 / 侧栏大字 / 通栏条目 / 右侧条目 / 圆标编号）、
          标题层级（居中大字 / 左对齐 / 编号徽章 / 杂志细线 / 手写标注）、
          正文排布（双栏卡片 / 三栏卡片 / 四宫格图标 / 图文叙事 / 圆点三栏 /
          手写清单）、卡片圆角（0.02–0.26 英寸）、行距与留白节奏
          （0.16–0.28 英寸）、图片位（居中 / 右侧 / 左侧 / 环形 / 不用图）。
       · 预览和导出的 pptx 读的是同一份版式坐标（同一个 smLayOf / SM_TLAY），
         所以预览里看到的排法就是导出后的排法，不是两套各画一遍。
       · 选了模板后会自动切到「智能版式」，因为模板的排版只在这一模式下生效；
         想回到「按主题自动挑」点「AI 自动匹配」，想不套模板点「基础配色」。
     · 优先级：手动选的模板 > 基础配色 > 自动匹配。
     · 页面不再单独调色：配色、字体、装饰母题、版式几何四项全部由所选模板接管。
     · 说明：网页里内置的是每套模板的「版式 DNA + 配色 + 字体」和一张原版封面，
       真正的 .pptx 原件原样放在「模板库」文件夹（11 份合计约 217 MB），
       所以断网也能用；网页本身仍是单文件，不读原件也能出片。
     · 模板选的字体若本机没装，网页会自动回退到相近字体，导出仍可正常打开。
     · 更细的用法（自动匹配怎么算、实测结果、换模板换什么）见文末
       「附：模板库怎么用」。
3. 「视觉预览」里能直接看到 15 页的真实版式：点任意缩略图放大，
   用 ← → 翻页，Esc 关闭；换模板时预览会同步变化。
   也可以点「一键生成 PPTX」旁边的「视觉预览」按钮从第 1 页开始看。
4. 点「一键生成 PPTX」，浏览器会直接下载一份 15 页的课件，
   文件名形如「初二_情绪管理_课件.pptx」，讲师备注也会一起写进去。
· 全程在本机完成，不需要联网，也不会把内容传到任何地方。
· 勾选「生成后自动记入课程排期」，课件条目会出现在「课程排期」里。
· 生成的是可编辑的 pptx，下载后可以自己改字、换图。
· 手机上保存位置：iPhone 在「文件 → 下载」，安卓在「下载 / Download」目录，
  也可以直接用 WPS 手机版打开放映。

5. 想让版式跟着你的要求走（可选，要自己有对话模型接口）：
   在「生成要求」里写人话，例如「初三、节奏紧、多用流程和数据、结尾落到行动」，
   再到下面「API 配置」卡里填接口地址、对话模型（如 deepseek-chat）和 Key，
   点「AI 编排版式」。模型只负责「排页面」，不编新内容：
   · 页面顺序、每页用哪种版式由它决定，文案仍取自这门课的内置内容；
   · 排好后大纲、页数、视觉预览立刻同步，讲师备注一起给；
   · 点提示里的「恢复内置版式」可以随时还原；
   · 求助页（12356 / 12355 / 110 / 120）和讲师页始终保留，不会被排掉；
   · 不填也能用：默认就是内置版式，不需要联网。

6. 按自己的教案 / 课本照片出课件（本轮升级）
   位置：「一键出课件」→「课程设置」卡里，从上到下依次是：
   教学资料 → 教案/课本文字 → 热身活动库 → 插画素材库。

   【教学资料】点「上传照片 / PDF / DOCX」可一次选多个文件（也可分多次追加）：
   · 支持：jpg / jpeg / png / webp 照片、.pdf、.docx 教案、.txt / .md 文字稿。
   · 每个文件显示文件名、类型、大小和解析状态；图片可直接点开预览。
   · 文件按列表顺序处理，可用「上移 / 下移」调顺序、点「×」删除后重传。
   · 单个文件上限 25 MB，最多 12 份资料；格式不对、超限、重复、读取失败
     都会在文件行里写明原因。
   · 照片用「视觉模型」识别（OCR + 版面理解）；PDF 提取文字层（扫描版
     PDF 无文字层会明确提示「请改用照片或粘贴文字」，不会瞎编）；DOCX 直接解包读正文。
   · 解析结果按教材章节写入「教案 / 课本文字」大框（识别只转录真实文字，
     看不清处标「（此处模糊）」，不补造原文）；AI 排出的页面属于据原文的整理，
     与原文分开，都可手动改。
   · 点「解析资料并排课」：先解析，再自动按教案排课，一步到位。
     也可以只点「按教案排课」或直接「一键生成 PPTX」（有字就自动排）。

   【热身活动库】真正可维护的库，不只是文本框：
   · 点「导入 Excel 到活动库」读 .xlsx / .csv，列依次为：
     活动名称 / 主题标签 / 适用年级 / 时长 / 人数 / 道具 / 活动步骤 /
     教师引导语 / 复盘问题 / 注意事项（表头可省略，按列序读）。
   · 「管理活动库」里可搜索、按主题与年级筛选、新增、编辑、删除、查看步骤。
   · 「导出 Excel」把当前库导出成 .xlsx，可改完再导回。
   · 排课时按主题、年级、时长、人数、道具条件打分匹配，优先用库里的活动；
     没有合适活动时会写「AI 新拟方案」，并在备注里注明，不冒充库内原有活动。

   【插画素材库】真实图片文件 + 索引数据，存在本机浏览器里（上限 12 张）：
   · 点「上传插画」可多选；每张可填主题、情绪标签、适用年级、风格、
     来源、授权信息，并可预览、替换图片、删除。
   · 「管理素材库」里可按关键词 / 主题 / 情绪搜索，也能看到分类与标签。
   · 配图优先级：教材原有图片 → 你上传的照片 → 素材库匹配 → 纯图形色块。
     不会每页硬塞图。
   · 素材库为空或没匹配上时，状态行与质检都会如实写「素材库无匹配，该页留白」，
     不会伪造素材命中。

   【流程状态】生成时顶部状态条按真实进度推进：
   待上传 → 正在解析 → 正在设计课堂 → 正在匹配活动 → 正在匹配图片 →
   正在生成 PPT → 正在检查 → 生成完成。
   每一步都由实际处理结果点亮，失败会停在对应阶段并给出原因，不是定时假进度。

   【生成之后】右侧「大纲预览」「视觉预览」同步刷新，可做这些事：
   · 下载 PPTX / 「再次下载」同一份文件。
   · 「编辑大纲」（先改结构再出片）：逐页改标题、版式、要点、讲师备注，
     ↑↓ 调序、复制、删除、新增（限 10–18 页）；封面、求助页、讲师页、
     结束页锁定不可删，避免误删危机资源。保存后页数、预览立即更新，
     再点生成会沿用这份大纲，不会把你的页数改回去。
   · 「导出大纲」：把当前大纲导出为 Markdown，便于备课组传阅或再粘回教案。
   · 缩略图右上角「操作」：
     – 直接改这一页的标题、要点、讲师备注（副标题、引文只在封面、引文页、
       结束页显示；其他版式不显示时就不出现该输入框，避免改了看不到）；
     – 换图：从素材库、上传照片里选，或设为「自动匹配 / 本页无图」；
     – 「本页要求」写一句额外要求，再点「AI 重写这一页」，只改这一页，
       其他页与已换好的图都不动。
     改完再点「一键生成 PPTX」，会沿用当前大纲（保留你的单页修改与换图），
     直接出新的 pptx，不会把你改的内容冲掉。
   · 「版本」：本会话每次生成存一版，可查看页数、时间并恢复旧版。
   · 「质量检查」：检查页数、空白页、文字溢出、图片缺失/变形、内容重复、
     时长分配、活动与目标是否对应、教案知识点是否遗漏；
     「一键修复可自动处理项」能修的自动修，修不了的会写清是哪一页、什么问题。
   · 生成后还会校验文件本身：能否解析、实际页数与大纲是否一致。

   【边界与配置】
   · 识别照片需要支持图片输入的模型：在「API 配置」最下面「视觉模型」里填
     （如 doubao-seed-1-6、Qwen2.5-VL、gpt-4o-mini），留空则用上面的对话模型。
   · 不配模型也能用：照片会退回「手动粘贴文字」，排课走本地解析（15 页），
     一样能出可编辑 pptx，只是不调用 AI。
   · 所有资料和图片只存在这台设备的浏览器里，不上传任何服务器；
     Key 不写进页面源码、不打印到控制台、不出现在接口响应里，只在浏览器本地存储。

附：让 AI 写这一课（可选，要自己有接口）
· 位置：「一键出课件」→「课程设置」卡下面的「API 配置」卡
  （默认收起，点标题栏展开 / 收起；标题右侧显示「已配置 / 未配置」。
  手机上它在视觉预览的下面）。
  兼容 OpenAI 协议的任意服务都行：官方、中转、通义、DeepSeek。
· 三个空：接口地址（如 https://api.deepseek.com/v1，填到 /v1 即可）、
  模型（按服务商文档写，如 deepseek-chat）、API Key。
· 卡片上方有三个预置：点「DeepSeek 官方」「硅基流动」或「火山方舟 · 豆包」，
  会自动填好地址和模型，再粘自己的 Key 就行。
  · DeepSeek 官方与硅基流动实测允许浏览器直连；
  · 火山方舟（模型 doubao-seed-1-6）官方接口对浏览器跨域支持不稳定，
    若测试连接报「连不上 ark.cn-beijing.volces.com」，说明浏览器直连不了，换前两家。
· 模型要填「对话模型」：gpt-image-*、dall-e、flux、kolors、cogview 这些是生图模型，
  填了会直接提示，不会去请求接口。
· 报「连不上 xxx.com」多半不是 Key 的问题，而是这个地址没给浏览器开跨域（CORS）：
  中转站（尤其 xxx.com 这类网关面板）默认关闭，需要站长发开「允许跨域」才能用；
  换 DeepSeek 官方 / 硅基流动最省事。
· 点「保存」→ 点「测试连接」确认能通 → 点「AI 写这一课」，等十几秒，
  这一课的 15 页会换成 AI 写的文案：大纲、视觉预览、导出的 pptx 一起变，
  连每页顶部那句手账说明（第 1–15 页）也会跟着变。
· 只影响当前选中的主题；换回别的主题仍用内置文案。
  想改回内置：点状态行后面的「恢复内置」，或说明文字里的「清空 Key」。
· Key 只存在你这台设备浏览器的存储里，不上传任何服务器（也不进同步的 Gist）；
  公用电脑上用完建议清空。浏览器直连要求接口允许跨域（CORS），
  连不上时先看状态行的橙色提示，多半是地址不对、网络不通或该服务不允许跨域。
· 不填也能照常用：没配置、断网、接口报错时自动回落内置文案，出片不受影响。

二、自动匹配是怎么算的
不用你选，引擎按下面几项打分取最高（同分按内置顺序，结果稳定）：
· 主题词命中 +6 / 个，最多算 3 个——主题才是你想表达什么，权重最高；
· 教案正文（生成要求 / 教案 / 活动库）里的同批词另算 +1 / 个，最多 3 个——
  正文里「方法 / 目标」这类词太常见，混在一起算会让所有主题都塌到同一套；
· 学段 +4——最稳的信号（小学 / 初中 / 高中三档，写「一年级」「初二」
  「高二」都认）；
· 版式 +2（现在只有「智能版式」「海报卡片」两种）；
· 当前配色 +1（配色槽位固定「暖阳手账」，模板里带暖阳偏好的 +1）；
· 关掉「自动配图」时，本身不靠图的模板 +2；
· 通用型模板带基础分兜底（可爱小怪兽 +1，卡通手绘说课 +0.6，
  可爱泡泡 +0.6），冷门主题也不会落空；
· 主题或正文里出现「危机 / 自杀 / 自伤 / 欺凌 / 霸凌 / 预警 / 干预」时，
  小清新动物教学额外 +6（严肃议题优先）；
· 同分时取排在前面的模板（每往后一位 -0.01），所以同样的输入每次结果一样。

五、换一套模板，到底换什么
换的是一整套设计 DNA，四层：
① 配色：每套 9 个色值（底色 / 深底 / 卡片 / 主文 / 次文 / 主色 / 辅色 /
  柔和色 / 描边）。
② 字体：标题字体 + 正文字体（各带缺字回退）。
③ 装饰母题：圆角色块 / 波浪 / 竖网格 / 圆点 / 圆点阵 / 极简细线 / 纸胶带 /
  叶形 / 画框（随「智能版式」绘制；海报卡片有自己的色块语言）。
④ 版式几何——这才是「排版」本身，11 套各不相同：

  模板            封面构图    目录排法    页标题排法  正文排布
  可爱兔子        居中堆叠    四象限      居中堆叠    双栏卡片
  可爱小怪兽      图像分栏    阶梯编号    编号徽章    三栏卡片
  卡通油画质感    居中堆叠    双栏大号    居中堆叠    三栏卡片
  卡通教学通用    右对齐大字  侧栏大字    左文右图    四宫格图标
  卡通手绘说课    手账信纸    手写清单    手写标注    手写标注
  卡通风教学通用  左文右图    通栏条目    大号序号    双栏卡片
  小清新动物教学  上图下文    右侧条目    杂志细线    杂志细线
  卡通手绘课件    居中堆叠    居中条目    居中堆叠    图文叙事
  快乐的恐龙      右对齐大字  右侧条目    左文右图    左图右文
  食品安全主题班会 插画框景   四象限      居中堆叠    图文叙事
  可爱泡泡        奶油色块    圆标编号    编号徽章    圆点三栏

  此外每套还各带：卡片圆角（0.02–0.26 英寸）、块间距（0.16–0.28 英寸）、
  标题字号（26–34pt，标题过长自动缩字）、图片位（居中 / 右侧 / 左侧 /
  环形 / 不用图）。
  · 所以同样是「一页三栏」，三套模板排出来是三张不同的版面，
    不是同一张版面换个颜色：11 套的版式参数两两不同。
  · 预览和导出的 pptx 读的是同一份版式坐标（同一个 smLayOf / SM_TLAY），
    所以预览里看到的排法就是导出后的排法，不是两套各画一遍。

· 海报卡片的色块跟着模板主色走，但版式几何是它自己那一套。
· AI 编排时的语气提示：每套模板带一句风格说明，会写进提示词。
· 导出文件的元信息：pptx「主题」一栏写「模板：X · 字体：ft / fb」。
不变的是：页数、页面类型顺序、文案与讲师备注。

六、模板和 AI 写文案是什么关系
· 模板只管「视觉长相」和「语气取向」，不替你写内容。
· 配了接口点「AI 写这一课 / AI 编排版式」时，提示词会带上当前模板名和
  那句风格说明，让标题长短、配图取向贴合这套模板；选「基础配色」时
  只带配色名（暖阳手账），没有模板风格说明。
· 没接口、断网、接口报错时，模板照样生效，只是文案用内置的。

七、优先级（谁压谁）
手动选的模板 > 基础配色 > 自动匹配。
页面底部那行元信息（「15 页 · 16:9 · 智能版式 · 可爱兔子 · 含讲师备注」）
里的名字，就是最终生效的那一套。

八、字体缺失怎么办
· 模板的标题字体（汉仪字研欢乐宋W、字魂27号-布丁体、Senty小丸子、
  胡晓波骚包体、方正卡通简体……）多数电脑没装，
  网页会先探测，再回退到相近字体（幼圆 / 楷体 / 微软雅黑 / 等线）。
· pptx 里写的是回退后的字体名，所以在别人电脑上打开不会整篇变宋体；
  想完全还原模板字形，把该字体装到这台电脑即可。

九、会不会记住
· 会。选择记在这台设备的浏览器里，下次打开还是上次那套。
· 开了「云端同步」时，模板选择随数据一起同步到另一台设备；
  但 API Key 不参与同步，两者是两回事。
